# ⏳ Professional Age Calculator

A highly accurate and beautifully designed web-based Age Calculator[cite: 3]. This project demonstrates advanced date manipulation using Vanilla JavaScript alongside modern UI/UX principles like Glassmorphism and CSS gradients[cite: 4, 5].

## 🚀 Tech Stack
* **Frontend Structure:** HTML5
* **Styling:** CSS3 (Glassmorphism, Custom Variables, Flexbox)
* **Logic:** JavaScript (Vanilla JS, DOM Manipulation, Date Objects)
* **Icons:** Ionicons Open-Source Library

## ✨ Key Features & Functionality

* **Precision Calculation:** Accurately computes the exact difference between two dates in Years, Months, and Days, automatically adjusting for varying days in different months[cite: 4].
* **Smart Defaults:** The application automatically sets the "Age at the Date of" field to the user's current local date upon loading[cite: 4].
* **Form Validation:** Includes built-in error handling that alerts the user with a prompt if they attempt to calculate without selecting both dates[cite: 4].
* **Quick Reset:** Features a dedicated refresh button that clears the Date of Birth input and instantly resets the target date back to today[cite: 4].
* **Glassmorphism UI:** The interface uses a dark background with a semi-transparent glass container, utilizing `backdrop-filter: blur(10px)` for a modern, sleek look[cite: 5].
* **Interactive Animations:** The UI incorporates engaging hover effects, such as a subtle lift on the calculate button and a 180-degree rotation on the refresh button[cite: 5].
* **Gold Gradient Accents:** Important interactive elements are highlighted using a custom gold linear gradient, providing a premium feel[cite: 5].

## 📂 File Structure
* **`index.html`**: Contains the semantic structure, input fields for dates, action buttons, and integrates external Ionicons[cite: 3].
* **`style.css`**: Manages the dark mode aesthetics, responsive layout, glassmorphism container, and smooth transition effects[cite: 5].
* **`script.js`**: Houses the core logic for the `calculateAgeDifference` function, event listeners, and dynamic DOM updates[cite: 4].

## 🛠️ How to Run This Project Locally
Open the Folder: Navigate into the downloaded project directory.
Launch the App: Double-click the index.html file to run the application directly in any modern web browser. No local server is required.
